# Felhasználói képernyőbizonyíték: Onapsis-ellenőrzés

Dátum: 2026-10-18. A Z_CONTROL_FOR_CODE variáns kibontását kérő válaszra a felhasználó képernyőképet adott át.

Látható kijelölt ág: Control for Code Check → Control for Code by Onapsis. A vizsgálat be van jelölve. A kivágáson a variánsnév/SID nem látszik; a variánshoz kapcsolás beszélgetési kontextuson alapul. Ez a megjelenített vizsgálati konfiguráció bizonyítéka, nem önálló SAP-visszaolvasás vagy sikeres QA-futási eredmény.

Nem látszik a teljes Onapsis-szabálycsomag, policy, tesztesetek, prioritások vagy kivételek listája, illetve az elengedéskori variánshozzárendelés. A skill referenciái e különbséget megőrzik.
